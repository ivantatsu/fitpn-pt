# FitPN · Frontend (Angular 22)

SPA de la plataforma FitPN. Consulta el [README principal](../README.md) para ver la arquitectura,
la configuración y el despliegue.

```bash
npm install
npm start               # http://localhost:4200 (proxy /api → http://localhost:8080)
npx ng test --watch=false
npx ng build            # salida en dist/fitpn/browser
npm run format          # prettier
```
